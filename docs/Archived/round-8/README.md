## 固定执行顺序

```text
架构与音频底座（A0–A5）
  → 算法重构（A6）
  → UI/UX 生产重构（A7）
```

设计原型可在架构工作期间并行探索，但不得在旧 Supabase 直连、旧音频依赖或旧项目状态模型上继续叠加生产主流程。

## 当前范围边界

- 不迁移旧 Supabase 测试数据。
- 保留 React + Vite 工作台，新增自有 API 与可运营的数据/资产层。
- 默认音频必须零网络首播；高质量采样为渐进增强。
- 旋律编辑与和声审阅保留为两个明确阶段；和声阶段的底部抽屉只显示 chord 名称。
