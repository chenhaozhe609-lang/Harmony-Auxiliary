# A6：和声生成模型任务书

> 状态：待实施。
> 前置条件：A0–A5 已通过 M3 生产基线；参考 [02-algorithm-audit.md](02-algorithm-audit.md)。
> 目标：从线性和弦标签选择升级为带乐句计划、终止意图、连续风格与一致配声输出的生成模型。

## ALG-06.1：建立可审计的评估基线

| 子任务 | 交付物 | 验收标准 |
| --- | --- | --- |
| 定义测试样例 schema | 旋律、拍号、调式、乐句边界、结尾意图、人工备注字段 | 测试样例可被机器读取和版本化；不把预期仅写在测试注释中 |
| 建立覆盖矩阵 | 大小调、Dorian、Mixolydian、2/4、3/4、4/4、6/8、末音、密度、意图矩阵 | 每一个维度至少有代表样例；矩阵缺口可见 |
| 补充基准回归 | 现有短例 + 已复现长旋律失败例 + 手动编辑例 | 可复现审计中的未收束结尾；修复后不会仅靠改测试期望掩盖问题 |
| 定义质量判定 | 机器可判定规则 + 听感人工审阅表 | 明确哪些是硬约束（终止/一致性），哪些是偏好（色彩/多样性） |

**退出门槛：** 在不改生成算法的情况下，评估命令能稳定给出覆盖、硬失败与候选对比结果。

## ALG-06.2：建立乐句计划与结尾意图

| 子任务 | 交付物 | 验收标准 |
| --- | --- | --- |
| 设计 `PhrasePlan` 领域对象 | 乐句边界、置信度、`continue/open/half/full/loop` 意图 | 对象可被保存到项目修订并被 UI 编辑；不依赖“最后三个片段”推断 |
| 实现自动边界建议 | 基于节拍、休止、长音、重复与旋律重音的可解释建议 | 不确定时返回可修正建议，而非伪装为确定结论 |
| 提供用户覆写接口 | 乐句切分/结尾意图的输入契约与最小 UI 接点 | 覆写后下一次生成严格以覆写计划为输入 |
| 定义终止模板库 | 与调式、末音、意图相容的完整/半终止/开放/循环模板 | 高色彩路径可变，但各模板的解决规则与禁止条件明确 |

**退出门槛：** 同一旋律分别标记“完整结束”和“循环”时，输出目标明显不同，且循环不会被机械落主。

## ALG-06.3：将终止和风格纳入全局搜索

| 子任务 | 交付物 | 验收标准 |
| --- | --- | --- |
| 重构搜索状态 | 候选包含和弦、乐句位置、终止状态、可播放 `Voicing` 的必要信息 | 搜索不能在后处理阶段另造与评分无关的终止/配声 |
| 在搜索中执行终止约束 | 受约束全局搜索或等价的状态转移逻辑 | `full` 意图的主候选没有未解决属功能或不稳定结束；不靠事后强塞 I |
| 建立连续 `StyleSpectrum` | 0–100 参数映射、插值/采样策略与稳定性规则 | 相邻数值没有不可解释的词汇断层；0 与 100 有可感知差异 |
| 分离风格与乐句意图 | 搜索输入与产品语义 | 任一风格值都遵守完整终止底线；风格不充当“是否收束”的开关 |
| 产生 n-best 方案 | 可比较路径、去重与差异度规则 | 候选来自同一目标函数的 n-best 路径，不是三套离散 profile 的单解拼贴 |

**退出门槛：** 回归集中所有 `full` 样例主候选满足终止约束；连续滑动 0–100 可生成稳定、可解释的中间结果。

## ALG-06.4：统一配声、评分和渲染

| 子任务 | 交付物 | 验收标准 |
| --- | --- | --- |
| 定义共享 `Voicing` 模型 | 和弦标签、低音、声部音高、时值、来源/置信度 | 搜索、UI、试听、钢琴卷帘和 MIDI 导出消费同一对象 |
| 把配声纳入目标函数 | 声部进行、旋律冲突、音域、终止解决的评分分项 | 评分不再只对和弦标签打分后另行分配转位 |
| 建立可解释评分 | 功能、终止、旋律适配、声部进行、色彩及总分的分解 | 总分可由分项复算；界面解释不展示虚假的合成分数 |
| 验证跨输出一致性 | 候选快照与音高比对测试 | 同一候选在搜索结果、试听事件、卷帘和 MIDI 音符上完全一致 |

**退出门槛：** 针对代表候选的自动化音高快照测试通过，人工试听与可视化没有不一致。

## ALG-06.5：实现上下文编辑与局部再优化

| 子任务 | 交付物 | 验收标准 |
| --- | --- | --- |
| 定义编辑约束 | 锁定和弦、替换偏好、不可改变区间、允许重算窗口 | 用户操作保留为显式约束，不被下一次生成静默丢弃 |
| 实现邻域重优化 | 替换点附近及同乐句终止条件的局部搜索 | 替换后检查前后连接、低音/声部进行和句末条件，而非孤立替换标签 |
| 输出变更解释 | 修改前后差异与受影响区间 | 用户能区分“自己锁定的和弦”和“系统为保持连贯性调整的邻居” |
| 增加编辑回归 | 替换靠近句尾、跨乐句、循环意图等样例 | 手动编辑不破坏完整终止/循环语义，不引入评分与试听不一致 |

**退出门槛：** 句尾手动替换后的局部再优化有稳定测试，且不会破坏用户锁定项。

## ALG-06.6：算法验收与发布输入

- 对每个完整乐句样例，主候选满足其终止类型；高色彩值仍有解决。
- 对循环、继续和半终止意图，系统明确保留非完整终止，而不是一律回到主和弦。
- 风格光谱在 0、25、50、75、100 及相邻扰动处均有回归结果；中间值无硬编码三档跳变。
- n-best 候选保持可比较的目标函数与差异度；不重复展示等价结果。
- 搜索评分、可视配声、试听与导出音高一致。
- 生成延迟、候选数量、回归耗时有基准记录；超过既定预算须先优化或明确降级策略。
