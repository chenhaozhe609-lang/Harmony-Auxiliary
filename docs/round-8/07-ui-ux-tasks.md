# A7：两阶段工作台与体验任务书

> 状态：待实施。
> 前置条件：A0–A5 已完成生产切换；A6 已提供稳定的生成/配声契约与演示夹具。
> 参考：[03-ui-ux-audit.md](03-ui-ux-audit.md)。

## UI-07.1：建立信息架构与设计系统基线

| 子任务 | 交付物 | 验收标准 |
| --- | --- | --- |
| 固化两阶段状态模型 | 阶段定义、进入/返回/保存规则、键盘流程 | 阶段 1 始终以旋律编辑为目的，阶段 2 始终以和声审阅/编辑为目的；不把两者混成同一密度页面 |
| 设计浅色通透视觉 tokens | 色彩、层级、字阶、间距、圆角、阴影、动效与深色适配规则 | 默认不使用饱和纯黑或纯白作为大面积底色；强调色克制且对比度达标 |
| 拆分可复用基础组件 | 按钮、滑动条、分段状态、抽屉、检察器、轨道、空/加载/错误状态 | 组件 API 不依赖业务页面；交互状态含焦点、禁用、加载和键盘可达 |
| 改写现行 UI 设计文档 | 更新 `docs/UI_UX_DESIGN.md` 或其替代文件 | 删除与新方向冲突的黑色奢侈画廊默认定义；以本轮阶段规则为唯一依据 |

**退出门槛：** 阶段 1/2、桌面/移动四个关键状态具有可审阅的布局和交互规格；不是只提供静态皮肤。

## UI-07.2：重构阶段 1（旋律编辑）

| 子任务 | 交付物 | 验收标准 |
| --- | --- | --- |
| 建立编辑主画布 | 具有充分高度的钢琴卷帘、节拍标尺和可见编辑工具 | 首屏唯一明显主画布是卷帘；新增、选择、移动、删除等高频操作不依赖“更多”菜单 |
| 改造音符拖拽 | 连续预览、可见吸附、提交节流/结束提交策略 | 指针移动不触发整页可感知跳动；用户能预见落点和节拍吸附 |
| 收纳生成上下文 | 可折叠但状态可读的调式、拍号、速度、乐句和风格设置 | 展开/收起均能识别当前值；低频设置不与编辑动作争夺顶栏 |
| 明确空、加载、失败状态 | 本地模式、同步、生成、音频不可用提示 | 异常不会把编辑画布替换为无解释空白；可继续的操作明确可见 |

**退出门槛：** 新用户能在不打开二级菜单的情况下输入旋律、调整关键上下文并开始生成。

## UI-07.3：重构阶段 2（和声审阅与编辑）

| 子任务 | 交付物 | 验收标准 |
| --- | --- | --- |
| 将 Chord Track 设为主画布 | 当前方案、时间轴和和弦块编辑区域 | 阶段 2 首屏中 Chord Track 是唯一明显主画布；旋律降为紧凑只读参考，不能挤占主体高度 |
| 实现和弦块操作 | 选中、替换、锁定、比较候选、局部重新生成 | 操作直接作用于 A6 的编辑约束和局部再优化契约；不在 UI 端伪造音乐规则 |
| 改造底部抽屉 | 简洁 chord 时间线 | 默认只显示 `C`、`Am/C`、`Fmaj7` 等和弦名称；绝不显示 `E2`、声部行或完整 voicing |
| 建立按需检察器 | 终止意图、功能解释、候选差异、专业配声详情入口 | 未选择和弦时不显示冗余长文；详细音高只在显式展开的详情/未来专业配声视图中出现 |
| 重排播放与候选入口 | 当前方案试听、A/B 比较、候选列表 | 候选是 A6 返回的可比较方案；风格不再被伪装成三档候选卡 |

**退出门槛：** 用户能在阶段 2 浏览整句和声、听取、替换/锁定一个和弦、理解改变原因，而主画布始终保持可见。

## UI-07.4：接入连续风格、乐句与同步反馈

| 子任务 | 交付物 | 验收标准 |
| --- | --- | --- |
| 用连续滑动条替换三档风格 | 0–100 风格控件、可访问数值标签和语义提示 | 页面没有三档风格按钮或同义卡片；键盘可精细调节；控件不暗示“越高越不收束” |
| 暴露乐句与结尾意图 | 可查看/修正的乐句边界与 `full/half/open/continue/loop` 控件 | 风格与结尾意图独立设置；完整结束、循环等意图对用户可见 |
| 呈现本地优先状态 | 保存中、已本地保存、待同步、冲突、离线、已同步反馈 | 用户可知道修改是否安全留在本地、是否上传成功；冲突有明确处理入口 |
| 接入音频渐进状态 | 可用 fallback、采样加载、缓存可用/失败状态 | 不以 loading 遮挡首播；资源失败仍可试听，并给出非打扰式说明 |

**退出门槛：** 风格、乐句、同步和音频四类状态均有不阻塞创作的可理解反馈。

## UI-07.5：响应式、可访问性与视觉细修

| 子任务 | 交付物 | 验收标准 |
| --- | --- | --- |
| 移动端任务优先布局 | 阶段 1/2 移动布局和触控手势规则 | 不只是缩小桌面；每一阶段仍有唯一主画布，高频操作可触达 |
| 键盘与辅助技术支持 | 快捷键、焦点顺序、ARIA 标签、读屏摘要 | 关键编辑、播放、阶段切换和滑动条可通过键盘完成；焦点不陷入抽屉/菜单 |
| 视觉与动效性能优化 | 降低重排、合成层/动效策略、减少动态偏好 | 拖拽、播放指示和抽屉动画流畅；尊重 `prefers-reduced-motion` |
| 视觉回归测试 | 关键状态截图和交互回归 | 桌面/移动、浅色/必要深色、阶段 1/2、抽屉/检察器状态均可比对 |

**退出门槛：** 在目标桌面与移动尺寸下完成核心路径检查，且没有以可访问性或性能换取视觉效果。

## A7 最终验收

- 阶段 1 的卷帘、阶段 2 的 Chord Track 分别是唯一清晰主画布。
- 和声阶段的底部抽屉仅显示 chord 名称；默认不出现任何具体音高和四声部信息。
- 连续风格滑动条是唯一风格入口；结尾意图与风格独立。
- 选中和弦可在当前画布中查看解释与替代方案；未选中时界面不堆叠无关信息。
- 音符拖拽的预览与吸附连续、稳定；桌面和移动端都能完成关键任务。
- UI 使用 A6 的真实夹具与 A2/A3/A4 状态，不以 mock 数据掩盖同步、音频或生成失败状态。
