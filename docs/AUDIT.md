# 代码审计与功能简化

日期：2026-10-07。范围：当前工作区入口、账户与项目存储、自动保存、音频启动、构建依赖，以及音乐核心代码中的主要边界。

## 当前产品边界

免登录的本地和声工具。保留 MIDI 导入与手动编辑、三种和声候选、试听、和弦替换、MIDI 导出、操作引导和本地项目管理。本轮未改写和声搜索与评分模型。

用户本轮要求简化并移除登录，覆盖历史第八轮计划中的云端账户、API、数据库和同步建设方向。历史审计中的算法质量问题仍可作为后续参考。

## 已解决的问题

| 问题 | 影响 | 本轮处理 |
| --- | --- | --- |
| 工作区入口依赖认证状态，外部服务失效影响本地创作 | 无法直接进入正式工作区 | 删除 AuthProvider、登录/注册面板、软门禁、登出重定向及账户按钮 |
| 云端项目与 Supabase SDK 直连 | 保存必须有账户且依赖远端服务 | 移除 SDK、客户端、云端仓库、迁移 SQL、云端迁移提示及相关文案；使用原 IndexedDB 中的 projects 表保存本地项目 |
| API 只有健康检查占位，共享包全部为空 | 增加工作区与构建复杂度，无实际业务价值 | 删除 apps/api、空 domain/contracts/harmony-core 包及 infra 占位；仅构建 apps/web |
| MIDI 导出已使用 @tonejs/midi，midi-writer-js 无调用 | 多余生产依赖及生命周期脚本 | 移除 midi-writer-js 及其构建许可配置 |
| IndexedDB 请求成功即被视为保存成功 | 事务随后回滚仍可能显示保存成功 | 等待事务 oncomplete，失败/中止向上抛出；新增事务中止回归 |
| 删除数据库 onblocked 被视为成功 | 其他标签页持有连接时数据没有清除 | 改为同一事务清空项目、草稿和导入表，保留原数据库版本及已有草稿兼容性 |
| 新草稿覆盖尚未确认恢复的旧草稿 | 刷新或打开示例可能丢失原工作 | 恢复读取完成且用户作出恢复/丢弃选择后再自动保存；清空时取消待执行保存 |
| 演示状态在旋律清空后自动重新填充 | 无法删除示例的最后一个音符 | 示例仅在进入示例路由时填充；清空本地数据后转为普通工作区 |
| 空旋律不更新草稿 | 删除全部音符后刷新仍可恢复旧旋律 | 空工作区删除旧自动保存记录 |
| 本地新导入/示例保留原项目 ID | 更新可能覆盖先前打开的项目 | 导入新 MIDI、加载示例与恢复草稿时解除原项目关联 |
| 首播等待远程采样下载 | 慢网或离线时试听阻塞 | 合成器立即播放，采样后台升级；以加载代数排除旧下载回调覆盖当前音色状态 |
| localStorage 写入异常从 React effect 逸出 | 禁用浏览器存储时可能白屏 | 偏好保存降级，项目存储失败在项目面板内显示可见错误 |
| 旧验收脚本依赖登录弹层及用户机器的运行时路径 | 无法验证免登录流程 | 删除账户/云端脚本，更新路由、引导与布局脚本，使用仓库内 Playwright 依赖新增完整浏览器回归 |

- 单元回归：17 个测试文件、90 项测试通过，包含本地项目 CRUD、草稿隔离、跨连接清空、事务中止、首播不等待采样及旧采样回调隔离。
